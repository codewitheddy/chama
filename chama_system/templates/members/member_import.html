CSV Format Guide

Your CSV must have these column headers in the first row:

name,phone,registration_fee,date_joined

Example rows:

John Doe,0712345678,500,2024-01-15
Jane Smith,0723456789,500,
  • name — required
  • phone — required, used to detect duplicates
  • registration_fee — optional, defaults to 0
  • date_joined — optional, formats: YYYY-MM-DD, DD/MM/YYYY
Column headers are case-insensitive — Name, NAME, and name all work. Files saved from Excel (with BOM) are also supported.
